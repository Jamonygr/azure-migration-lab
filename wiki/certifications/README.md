This lab supports selected Azure administration, architecture, and DevOps
learning objectives. It is not a complete exam course and does not promise
certification readiness.

The official study guides were reviewed on **29 October 2026**. Recheck them
before using an exam mapping; objectives change.

| Study direction | Relevant practice | Official source |
|---|---|---|
| AZ-104 | Azure compute, storage, networking, identities and operations | [Study guide](https://learn.microsoft.com/credentials/certifications/resources/study-guides/az-104) |
| AZ-305 | Migration choices, workload assessment, data destinations and recovery tradeoffs | [Study guide](https://learn.microsoft.com/credentials/certifications/resources/study-guides/az-305) |
| AZ-400 | Source control, quality gates, deployment authentication, artifacts and traceability | [Study guide](https://learn.microsoft.com/credentials/certifications/resources/study-guides/az-400) |

## Study method

For each scenario, explain the design before executing it. Capture evidence,
describe an alternative, and identify the limits of the result.

For architecture practice, compare rebuilding IIS with replicating a server and
with moving the app to a managed application service. For administration practice,
trace a failed readiness check through DNS, network, identity, and database
permissions. For DevOps practice, explain how a fresh runner can resume safely.

Use [the skill matrix](skill-matrix.md) to connect exercises to observable
capabilities. Do not infer a whole exam domain is covered because one service
appears in the repository.

## Deliverables

A completed scenario workbook, an architecture decision record, a rehearsal
report, and a short explanation of what additional validation a real workload
would require.
